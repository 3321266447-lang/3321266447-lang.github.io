# Python 入门

<p class="note-meta">📅 2026-10-08 · 🏷 编程基础</p>

## 一句话总结

> Python 是语法最接近英语的编程语言之一，非常适合入门。

## 变量

```python
name = "小明"
age = 18
print(f"{name} 今年 {age} 岁")
```

## 条件判断

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

## 循环

```python
for i in range(1, 6):
    print(i)   # 输出 1 到 5
```

## 函数

```python
def greet(name):
    return f"你好，{name}！"

print(greet("世界"))
```

?> 代码块右上角有 **复制** 按钮，可以一键复制。

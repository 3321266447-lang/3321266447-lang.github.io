📚 笔记管理后台

第一次使用需要一个 GitHub「访问令牌」，后台用它来帮你保存笔记。

怎么获取令牌？（只需要做一次）
  1. 打开 GitHub 新建令牌页面（要先登录 ）
  2. Token name 随便填，比如 笔记后台；Expiration 选有效期（可选 1 年）
  3. Repository access 选 Only select repositories，再选
  4. 在 Permissions 里点 ＋ 添加 Contents，设为 Read and write
  5. 点页面底部 Generate token，复制生成的 github_pat_… 粘贴到下面

令牌只保存在你自己的浏览器里，不会发送到 GitHub 以外的任何地方。在公共电脑上请取消「记住」。
